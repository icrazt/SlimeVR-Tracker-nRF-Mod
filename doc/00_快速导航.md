## 🚀 快速开始（5 分钟）

### 首次使用
```
1. 连接 USB 电缆
2. 等待 LED 指示（绿色表示就绪）
3. 运行 'battery' 命令检查电量
4. 阅读 [04 设备操作](04_设备操作与配置.md#1-用户界面和反馈机制) 了解 LED 和按钮
```

### 校准设备
```
1. 运行 '6边校准' (参考 [03 传感器与算法](03_传感器与算法.md))
2. 在不同温度下运行 T-Cal (可选，改进精度)
3. 等待校准完成并验证结果
```

### 优化功耗
```
1. 启用 WOM 模式 (CONFIG_USE_IMU_WAKE_UP=y)
2. 调整超时时间 (例如 CONFIG_ACTIVE_TIMEOUT_DELAY=300000)
3. 使用设备测试续航时间
4. 参考 [02 电源管理](02_工作模式与电源管理.md#81-功耗优化) 调细参数
```

## 💡 关键概念梳理

### 四元数坐标系
```
四元数 [w, x, y, z] 表示旋转：
  w: 旋转角度（余弦的一半）
  x, y, z: 旋转轴方向（正弦的一半）

与欧拉角的关系：
  roll  = atan2(2*(w*x + y*z), 1 - 2*(x² + y²))
  pitch = asin(2*(w*y - z*x))
  yaw   = atan2(2*(w*z + x*y), 1 - 2*(y² + z²))
```

### VQF 融合流程
```
输入: accel (重力) + gyro (旋转) + mag (磁北)
  ↓
计算修正向量
  ├─ 加速度修正: 对齐地球重力
  ├─ 陀螺积分: 预测四元数
  └─ 磁力修正: 修正偏航角
  ↓
加权融合 (SLERP)
  ├─ 根据噪声常数权衡信任度
  └─ 平滑融合旋转
  ↓
输出: 四元数 [w, x, y, z]
```

### 电源模式状态转换
```
用户启动设备
  ↓
ACTIVE (400 Hz 陀螺, 无线电活跃)
  ↓ (3 分钟无活动)
LPM1 (WOM 唤醒, ~1 mA)
  ↓ (1 小时无运动)
LPM2 (可选，超低功耗)
  ↓ (用户或超时)
SYSTEM_OFF (< 10 µA)
  ↓ (按钮/充电/运动)
ACTIVE (重新启动)
```

### 校准链
```
原始传感器数据
  ↓
应用 6 边加速度偏差校准
  ↓
应用软铁矫正矩阵
  ↓
应用 T-Cal 温度补偿 (陀螺)
  ↓
应用启动偏差校准 (陀螺)
  ↓
送入 VQF 融合
  ↓
输出: 准确的四元数
```

## 📱 设备交互快速手册

### LED 反馈
| LED 模式 | 含义 | 操作 |
|---------|------|------|
| 绿色常亮 | 已连接 | 正常工作 |
| 绿色闪烁 | 正在初始化 | 等待完成 |
| 黄色闪烁 | 寻找信号 | 检查主站 |
| 蓝色闪烁 | 配对模式 | 完成配对 |
| 红色快闪 | IMU 错误 | 检查硬件 |

### 按钮操作速查
| 操作 | 时机 | 结果 |
|------|------|------|
| 短按 | 启动时 | 继续启动 |
| 中按 (5s) | 启动时 | 重置配对 |
| 长按 (10s) | 运行时 | 进入关机 |
| 快速多按 | 任何时间 | DFU 准备 |
| + USB 插入 | 同时发生 | 进入 DFU |

### 控制台热键
| 命令 | 功能 | 典型输出 |
|------|------|---------|
| `battery` | 检查电量 | "3.8V (65%)" |
| `fusion` | 查看方向 | 四元数 [w,x,y,z] |
| `status` | 系统检查 | 各子系统状态 |
| `tcal status` | 校准进度 | "15 / 32 points" |
| `reset` | 重启设备 | 设备重启 |
