# SlimeVR Tracker nRF 固件官方文档

欢迎使用 SlimeVR Tracker nRF Mod 固件文档。本文档集提供了对该全身人体追踪系统完整的技术分析、架构设计、工作原理和使用指南。

## 📚 文档结构

### [01_系统整体架构.md](01_系统整体架构.md)
**应用人群**: 固件开发者、系统架构师、硬件工程师

本文档介绍了系统的整体设计和各个核心模块的结构：

- **项目概述**: 项目性质、目标平台、核心功能
- **系统架构图**: 分层设计全景
- **核心模块详解**: 
  - 传感器子系统 (IMU、磁力计、多驱动支持)
  - 通信子系统 (ESB 无线协议、数据包格式)
  - 电源管理子系统 (四级电源模式)
  - 系统初始化流程 (启动序列、复位检测)
- **数据流向**: 从传感器到无线传输的完整路径
- **多线程架构**: Zephyr 线程配置和线程间通信
- **存储架构**: RAM 分布、Flash 布局、掉电保留数据
- **DFU 机制**: 固件更新的原理和触发条件
- **编译配置**: 构建选项和 Kconfig 参数分类

**关键术语**:
- ESB: Enhanced ShockBurst (2.4GHz 无线协议)
- TDMA: 时分多址 (多追踪器同步)
- VQF: 向量四元数滤波器 (融合算法)
- NVS: 非易失性存储 (Flash)
- Retained: 掉电保留数据 (RAM)

### [02_工作模式与电源管理.md](02_工作模式与电源管理.md)
**应用人群**: 硬件设计师、固件优化工程师、低功耗专家

本文档深入讲解电源管理和工作模式的实现细节：

- **电源管理核心概念**: 设计目标、管制部件和功耗统计
- **四级电源模式详解**:
  - **ACTIVE**: 正常运行 (400 Hz 传感器, ~12-15 mA)
  - **LPM1**: 运动唤醒模式 (WOM, ~0.8-1.5 mA)
  - **LPM2**: 扩展低功耗 (可选, < 0.5 mA)
  - **SYSTEM_OFF**: 深度睡眠 (< 10 µA)
- **状态机转换**: 详细的模式切换条件和流程
- **电力路径**: DCDC vs LDO 稳压器的选择和切换
- **电池监控**: ADC 采样、电量映射、放电曲线跟踪
- **低功耗转换流程**: 从 ACTIVE 到 WOM 的完整步骤
- **看门狗集成**: 多通道看门狗的配置和超时处理
- **电源配置参考**: 关键的 prj.conf 和 Kconfig 参数
- **电源调试**: 控制台命令、示波器测量、优化建议

**核心概念**:
- **WOM (Wake-on-Motion)**: IMU 内部硬件运动检测
- **DCDC/LDO 切换**: 权衡效率和功耗
- **活跃超时**: 自动进入低功耗的计时器
- **电源请求**: 线程级别的电源状态控制

### [03_传感器与算法.md](03_传感器与算法.md)
**应用人群**: 算法工程师、校准专家、传感器集成开发者

本文档涵盖了传感器系统和 VQF 融合算法的所有方面：

- **传感器子系统概览**:
  - 6 种支持的 IMU 芯片 (BMI270, ICM42688, LSM6DS* 等)
  - 9 种支持的磁力计芯片
  - 多芯片自动检测机制
  
- **传感器初始化**: 自动检测、驱动接口、设备识别
  
- **传感器读取流程**: 
  - 主传感器线程 (400 Hz 周期)
  - FIFO 数据读取
  - 单位转换 (LSB → SI 单位)
  - 校准应用
  
- **VQF 算法详解**:
  - 什么是 VQF (向量四元数滤波器)
  - 四元数表示法
  - 外部库集成 (vqf-c)
  - 初始化和参数配置
  - 更新循环 (陀螺积分、重力修正、磁力计融合)
  
- **校准系统** (三层架构):
  - **6 边加速度校准**: 消除零偏和软铁矫正 (0g Offset)
  - **T-Cal 温度校准**: 连续温度桶采样、MLS/LUT 补偿陀螺零偏
  - **启动校准**: 基于 T-Cal 的 D_offset 校正
  
- **传感器配置参数**: 
  - ODR (采样率) 设置
  - 过采样因子
  - 量程选择 (FS)
  - 温度校准参数
  
- **磁力计集成**: 数据流、故障检测、软铁矫正
  
- **调优与校准方法**:
  - 静态精度测试
  - 动态追踪测试
  - T-Cal 最佳实践
  - VQF 参数调整指南
  
- **调试和监控**: 控制台命令、性能指标、功耗测量

**关键技术**:
- **FIFO 缓冲**: 高频数据的缓冲机制
- **软铁校正**: 磁力计的线性矫正矩阵
- **MLS/LUT**: T-Cal 的局部拟合和快速查表
- **四元数 SLERP**: 融合算法的线性插值方法

### [04_设备操作与配置.md](04_设备操作与配置.md)
**应用人群**: 最终用户、技术支持、集成商、应用开发者

本文档提供了使用和配置设备的完整指南：

- **用户界面和反馈机制**:
  - **LED 状态指示**: 闪烁模式含义、颜色编码、状态指示
  - **按钮操作**: 启动时、运行时、长按检测、DFU 模式触发
  
- **控制台命令接口**:
  - **访问方式**: UART 串行口或 USB CDC-ACM 虚拟 COM
  - **完整命令列表**: `info`, `battery`, `debug`, `tcal`, `dfu`, `dfu ota`, `reset *` 等
  - **远程预置命令**: `ESB_PONG_FLAG_*` 全量整理和函数对照

- **固件更新 (DFU) 流程**:
  - 控制台、按钮、远程预置命令、看门狗恢复等进入方式
  - USB/UF2、BLE OTA 和 nRF5 串口/二进制更新路径
  - 关键 magic 值和源码函数对照
  - 常见故障及排查
  
- **可配置参数**:
  - **运行时参数**: NVS 中的可改变配置 (配对地址、RF 频道等)
  - **编译时参数**: prj.conf 中的配置选项
  - **板级配置**: Device Tree overlay 中的硬件定义
  
- **故障排查指南**:
  - 常见症状和原因对应表
  - 逐步解决方案
  - 日志级别调整
  - 调试标志启用
  
- **性能优化**:
  - **功耗优化**: 场景 1-3 的配置建议
  - **延迟优化**: 最小化四元数延迟的方法
  - **精度优化**: 校准、振动隔离、磁场管理、算法调整
  
- **高级主题**:
  - 自定义 IMU/MAG 芯片支持
  - 自定义融合算法集成
  - 多设备同步 (TDMA)
  
- **性能基准**: 精度、延迟、功耗、通信可靠性的典型指标

**实用特性**:
- 即插即用的多芯片支持
- 自动传感器探测
- LED 和按钮反馈
- 无需特殊工具的固件更新
- 灵活的运行时配置

## 🛠️ 常见开发任务

### 任务 1: 添加新的传感器芯片支持

**步骤**: 
1. 阅读 [03_传感器与算法.md](03_传感器与算法.md) - 传感器初始化流程
2. 查看编码事例 (如 `src/sensor/imu/BMI270.c`)
3. 异议 WHO_AM_I 芯片 ID
4. 实现驱动接口函数
5. 注册至 `sensor_drivers[]` 表
6. 测试自动检测和读取

### 任务 2: 优化功耗

**步骤**:
1. 阅读 [02_工作模式与电源管理.md](02_工作模式与电源管理.md) - 电源模式详解
2. 选择适当的 `CONFIG_ACTIVE_TIMEOUT_DELAY` 和 `CONFIG_SENSOR_LP_TIMEOUT`
3. 启用或禁用 `CONFIG_WOM_USE_DCDC`
4. 使用示波器或电流表测量消耗
5. 运行长期续航测试

### 任务 3: 提高四元数精度

**步骤**:
1. 阅读 [03_传感器与算法.md](03_传感器与算法.md) - 校准系统和调优
2. 运行 6 边加速度校准
3. 运行 `tcal auto on` 并在温度范围内静止采集 T-Cal 数据
4. 调下 VQF 参数 (`tauAcc`, `tauMag`)
5. 用旋转测试台或手动验证

### 任务 4: 支持的代码解析

**步骤**:
1. 阅读 [01_系统整体架构.md](01_系统整体架构.md) - 多线程架构
2. 检查 `src/system/system.c` 中的线程定义
3. 添加新线程初心（参考现有线程模式）
4. 集成看门狗通道
5. 测试线程安全性 (互斥体、信号量)
